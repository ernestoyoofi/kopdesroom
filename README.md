# Kopdesroom

A web-based backroom game themed around a Koprasi Desa Merah Putih, which is really just a bit of fun or a joke.

The game's concept was developed by AI and humans, 94% of the coding was done by AI, whilst the debugging, sound, 3D graphics and other elements were created by me and some open-source materials.

Play? [kopdesroom.yupibknpermen.my.id](https://kopdesroom.yupibknpermen.my.id/), Inspiration? [Here](https://www.youtube.com/watch?v=MqDqREHvMhQ)
