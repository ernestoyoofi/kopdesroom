Information!

This game does not have mobile controls, it is only available for keyboard use.

Welcome To Kopdes!

  • Use WASD for walk
  • Click ESC for unfocus cursor
  • Use Q or E for peek
  • Hold Shift + walk for run
  • If you death, hit Enter to restart
  • Use Scroll Mouse for zoom in/out
  • Use Left Click for switch flashlight
